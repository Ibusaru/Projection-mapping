# 投影補正メモ

## 無料候補

### MapMap

無料・オープンソースのプロジェクションマッピングソフト。Windows対応。ウォーターマークなしで使える可能性が高く、今回の規模では最初に試す候補。

公式: https://mapmapteam.github.io/en/

### TouchDesigner Non-Commercial

非商用無料で使える。映像処理や補正は強いが、学習コストが高め。無料版は解像度制限があるため、本番の見え方を早めに確認する。

公式: https://derivative.ca/UserGuide/TouchDesigner_Non-Commercial

## 今回の補正方針

- 壁面をメイン画面にする。
- 天井側は水面の光、泡、ゆらぎなど背景演出にする。
- 魚やニックネームはなるべく壁面側に出す。
- 壁と天井の境目には重要な文字を置かない。
- プロジェクター位置は一度決めたらテープなどで固定する。

## 当日の調整手順

1. 投影面の寸法を測る。
2. PC、プロジェクター、投影ソフトを接続する。
3. Unityで格子状のテスト画像か明るい海中画面を表示する。
4. 壁面を四隅補正する。
5. 天井側を別の面として追加する。
6. 境目の歪みが目立つ場合、天井側の映像を背景寄りにする。
7. 本番前に暗さ、ピント、文字の読めやすさを確認する。
